# PathAsan Android

Native Android application built with Kotlin, Jetpack Compose, MapLibre, Google Play
Services Location, Geoapify Routing, and Room.

## Open in Android Studio

1. Open this `PathAsan-Updated` directory as the project.
2. Use JDK 17 and allow Android Studio to sync Gradle.
3. Copy `local.properties.example` to `local.properties`.
4. Keep the `sdk.dir` generated by Android Studio and set:

   ```properties
   GEOAPIFY_API_KEY=your_key_here
   ```

5. Do not commit `local.properties`. It is excluded by `.gitignore`.
6. Build and run on an Android 8.0 (API 26) or newer device/emulator with Google
   Play Services.

## Map and destination safety

- The map remains centered on Baguio City CBD and keeps the existing OpenFreeMap
  style.
- The four destination records supplied with the project brief are shown as
  **proposed, unverified locations**. They are not represented as officially
  designated evacuation centers.
- Before a production or emergency deployment, Baguio CDRRMO should verify each
  name, coordinate, description, designation, and current activation status.
- Walking routes require internet access. Downloaded MapLibre tiles do not provide
  offline routing.
- Confirm the current OpenFreeMap hosted-service terms and offline-use policy before
  production distribution. The project preserves the original provider and uses
  MapLibre's offline-region API, but this package does not assert a legal right to
  bulk-download a third-party hosted service.

See `MAP_REPAIR_REPORT.md` for the full audit and validation status.
